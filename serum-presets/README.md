# Drain Dreams — Serum 2 bank

17 Serum 2 presets in a Whitearmor / Yung Sherman / Blank Body style. The sounds are emotional, detuned and washed out. The only pitch offsets are whole octaves, so everything stays in key. Width comes from symmetric unison, chorus and Hyper. The tape wobble is a bipolar LFO on Fine pitch, centred on each note.

You need Serum 2. Serum 1 can't load `.SerumPreset` files. The presets use only factory wavetables and noises, so there is nothing else to install.

## Install

Copy the `Drain Dreams` folder to:

- **Windows:** `Documents\Xfer\Serum 2 Presets\Presets\User\`
- **macOS:** `/Library/Audio/Presets/Xfer Records/Serum 2 Presets/Presets/User/`

Then rescan the browser, or restart Serum.

## Rebuild / tweak

```bash
pip install -r tools/requirements.txt
python tools/build_presets.py            # writes ./Drain Dreams
```

Each preset is a single function in `tools/build_presets.py`. `tools/serum2.py` is the `.SerumPreset` writer: XferJson header, then a zstd-compressed CBOR state, with an MD5 hash of the zstd block. `tools/init_state.json` is the default state of Serum 2.0.24, and every preset starts from it.

## Notes

- The presets were generated by code and haven't been auditioned in Serum yet. I checked the format and every parameter key against presets saved by Serum 2 itself, and against the measured unit tables of [serum2vital](https://github.com/btesser/serum2vital).
- Wavetable positions on the long tables (Saw Drift, SynStringSaw, Solina Viola, Vocal Hum) were chosen by position, not by ear. Sweep WT POS on those to taste.
- Output levels are conservative (master 0.48–0.68). Gain-stage in your DAW.
